# Maths Studio

Maths Studio contains 80 templates for Classes 1–5, including 20 Primary Essentials templates.

- Select a template on the page and double-click its text to edit it. Enter saves, Shift+Enter inserts a new line, and Escape cancels. HTML captions and SVG diagram labels use the same editing behaviour.
- Use the Inspector to change width, height, position, typography and inner spacing. **Scale design** keeps the original layout inside the resized frame. **Reflow contents** asks the original renderer to adapt to the new dimensions.
- Double-click a shape, or choose a text, shape or panel in **Edit individual text, shapes & panels**. Change its offset, width/height scale, colour, border and visibility. Restore a part to remove its overrides.
- Mathematical Content exposes the template’s values, labels, lists and options. Lists have individual fields and Add/Remove actions, including bill items, chart categories, questions and MCQ choices.
- Editing a caption changes its presentation. Change operands under Mathematical Content to recalculate a model. Overrides on calculated labels stop applying when their underlying value changes, so a stale edited answer cannot conceal a new calculation.
- Save as Custom Template retains text edits, part styling, dimensions, typography, answer mode and design variant. My designs supports both click insertion and drag insertion.
- Insertions and content/design changes participate in undo/redo. Browser PDF and print scenes use the original rendered layout and current overrides rather than the older simplified substitute drawing.

Primary Essentials includes ten-frames, twenty-frames, count-and-write cards, hundred charts, doubles, multiplication tables, rounding lines, fractions of collections, fraction comparison bars, perimeter, area grids, metric conversion, elapsed time, factor pairs, coordinate grids and a daily practice card for each class.
