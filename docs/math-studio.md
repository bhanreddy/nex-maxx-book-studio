# Maths Studio

Maths Studio contains editable models and exercises for Classes 1–5, including Primary Essentials, ready-made worksheets, premium exercises and colourful arithmetic blocks.

- Select a template on the page and double-click its text to edit it. Enter saves, Shift+Enter inserts a new line, and Escape cancels. HTML captions and SVG diagram labels use the same editing behaviour.
- Use the Inspector to change width, height, position, typography and inner spacing. **Scale design** keeps the original layout inside the resized frame. **Auto resize** adjusts the text and artwork when width or height changes.
- Double-click a shape, or choose a text, shape or panel in **Edit individual text, shapes & panels**. Change its offset, width/height scale, colour, border and visibility. Restore a part to remove its overrides.
- Mathematical Content exposes the template’s values, labels, lists and options. Lists have individual fields and Add/Remove actions, including bill items, chart categories, questions and MCQ choices.
- Editing a caption changes its presentation. Change operands under Mathematical Content to recalculate a model. Overrides on calculated labels stop applying when their underlying value changes, so a stale edited answer cannot conceal a new calculation.
- Save as Custom Template retains text edits, part styling, dimensions, typography, answer mode and design variant. My designs supports both click insertion and drag insertion.
- Insertions and content/design changes participate in undo/redo. Browser PDF and print scenes use the original rendered layout and current overrides rather than the older simplified substitute drawing.

Primary Essentials includes ten-frames, twenty-frames, count-and-write cards, hundred charts, doubles, multiplication tables, rounding lines, fractions of collections, fraction comparison bars, perimeter, area grids, metric conversion, elapsed time, factor pairs, coordinate grids and a daily practice card for each class.

## Colourful arithmetic blocks

Open **Maths Studio → Arithmetic blocks** to find 35 native blocks rebuilt from the ten worksheet references. Filter by class, operation or **Reference Arithmetic Blocks**, or search for “lattice”, “borrowing” or “word problem”.

- Worked examples cover addition with and without regrouping, subtraction with and without borrowing (including through zero), multiplication with carries, zeros and partial products, lattice multiplication, and long division with exact answers, remainders and zeros in the quotient.
- Practice includes mental addition, grids for all four operations, mixed expressions with correct operation order, missing-number and missing-digit challenges, four word-problem workspaces, and one mixed practice block per class.
- Teaching blocks include division parts, the division check, repeated-subtraction counters, operation-selection cards, long-division steps and a checking checklist.

Change operands under **Mathematical Content** to update the arithmetic. For example, changing a division to `808 ÷ 8` produces the quotient `101`, and changing a subtraction to `1000 − 1` shows borrowing through both zero columns. Negative subtraction and division by zero show an editable validation message instead of changing the question silently.

Double-click headings, instructions, grid digits, step text or shapes to edit them. Authored headings, notes and labels update their data; calculated digits are presentation edits and reset when their source changes. Word-problem stories use `{{a}}` and `{{b}}` in the Story field so that changing the operands also changes the story.

Use **Text size**, **Question columns**, **Space between cards**, **Extra answer height**, **Accent palette**, custom colours, and **Monochrome printing** to adjust the design. Width changes scale the text, grids and artwork together; the block height follows the scaled content. Height changes keep the chosen width and fit the text and artwork uniformly into the new height. Letters retain their proportions. **Fit content** removes spare height. Individual parts retain the normal position, sizing, font, fill and border controls.

Student mode hides practice answers. **Show solved example to students** keeps worked examples visible when desired. Teacher mode fills the answer key. **Generate Similar (Local)** preserves supported arithmetic cases—for example, a no-carry addition stays without carries, and a division with a remainder keeps a non-zero remainder. Save and reuse edited blocks through **My designs**; click insertion and drag insertion both preserve the selected palette and answer mode.

The layouts use native SVG text and shapes for browser print/PDF export. No screenshot crops or full-page decorative artwork are embedded.
